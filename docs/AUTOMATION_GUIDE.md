# 자동화 실행 가이드 (매일 4시 리포트 생성)

이 문서는 **매일 장마감 후 자동으로 실행되는 세션**(Claude Code Remote Routine)이 따라야 할
절차다. 사람이 참고해도 되고, 스케줄된 세션이 이 문서를 읽고 그대로 수행해도 된다.

이 리포지토리는 KRX 데이터 서버(data.krx.co.kr)에 직접 접근이 막힌 네트워크에서도 동작하도록,
`WebSearch`로 시황·이슈를 조사해 JSON을 채우고 `scripts/render_report.py`로 포맷을 렌더링하는
방식을 기본 경로로 한다. (KRX 접근이 가능한 환경이면 `scripts/fetch_pykrx.py`로 지수/등락률
데이터를 더 정확하게 뽑아 뼈대로 쓸 수 있다.)

## 절차

1. **오늘 날짜/거래일 확인.** 오늘이 한국 증시 휴장일(주말/공휴일)이면 리포트를 생성하지 말고
   종료한다.

2. **시황 데이터 조사 (WebSearch/WebFetch).** 아래 항목을 조사한다.
   - 코스피/코스닥 종가, 등락폭(pt), 등락률(%), 거래대금
   - 원/달러 환율 종가 및 등락
   - 전일 미국 3대 지수(다우/S&P500/나스닥) 등락률
   - **업종별 등락률과 상대적 비중(시가총액 비중)** — 업종 히트맵(트리맵)에 쓰인다.
     10~15개 내외 업종을 조사해 `sectors` 배열로 정리한다 (`change_pct`, `weight`).
     `weight`는 **실제 시가총액 비중을 반영해야 한다** — 대충 비슷한 숫자를 나열하면
     안 된다. 예를 들어 반도체(삼성전자+SK하이닉스가 포함된)는 코스피 시가총액의
     20~30%대를 차지할 만큼 압도적으로 크고, 은행·화학·통신·유통 같은 업종은 그보다
     훨씬 작다 — 히트맵에서 반도체가 확실히 큰 블록으로, 나머지는 그보다 뚜렷하게
     작은 블록으로 나오도록 실제 규모감 있는 비율로 잡는다. 확실하지 않으면 업종별
     시가총액 순위/비중을 검색해서 확인한다 (예: `"코스피 업종별 시가총액 비중"`).
   - **오늘의 이슈 종목** 4~8개: 종목명, 코드, 등락률, 그리고 **왜 움직였는지 이유**
     (뉴스/공시/수급 근거를 반드시 포함 — "급등/급락"만 쓰지 말 것)
   - **헤드라인 한 줄**: 오늘 시장을 한 문장으로 요약하는 제목 (`headline`, 예:
     "고금리 압축 장세, 반도체 Top2로 쏠린 수급")
   - **본문 서술**: `market_summary_prose`(시장 전반 2~4문장), `sector_prose`(업종
     동향 2~3문장) — 애널리스트 리포트처럼 완결된 문장으로 서술한다 (불릿 나열 금지)
   - 검색 쿼리 예시: `"코스피 코스닥 마감 시황 YYYY년 M월 D일"`,
     `"YYYY년 M월 D일 특징주 급등 급락 이유"`, `"YYYY년 M월 D일 업종별 등락률"`
   - **여러 소스를 교차 확인**한다. 수치가 소스마다 다르면 가장 신뢰도 높은 소스
     (거래소 공식 발표, 주요 경제지)를 우선하고, 불확실하면 리포트에 "(추정치)"라고 표기한다.
   - 나무위키 등 사용자 편집 위키는 사실 확인 보조용으로만 쓰고 단독 근거로 삼지 않는다.

3. **단기 체크포인트 조사 — "뭘, 언제" 딱 짚어서.**
   - 오늘부터 앞으로 5~7일 내 예정된 구체적 이벤트를 **날짜(요일)를 명시해서** 찾는다:
     지표 발표(시간까지), 실적 발표, FOMC/한국은행 일정, 옵션만기 등 수급 이벤트,
     빅테크 실적 등. "미국 물가지표 발표 일정 확인"처럼 막연하게 쓰지 말고
     "8/28(금) 미국 7월 PCE 물가지표 발표 (21:30)"처럼 **날짜·요일·가능하면 시간**과
     **왜 중요한지**를 한 줄로 묶어서 쓴다.
   - `checkpoints` 배열에 `{"date": "8/28(금)", "event": "..."}` 형태로, **날짜 순으로
     정렬해서** 5개 내외 담는다. 가장 가까운 일정이 배열 맨 앞에 오면 리포트에서
     자동으로 강조 표시된다.
   - 검색 쿼리 예시: `"이번주 경제지표 일정 YYYY년 MM월"`, `"FOMC 일정 YYYY"`,
     `"이번주 실적 발표 기업 일정"`

4. **데이터 JSON 작성.** `reports/sample/2026-08-21_sample.json` 을 스키마 예시로 참고해
   `data/{YYYY-MM-DD}.json` 에 오늘 데이터를 채운다. (`data/` 디렉터리가 없으면 만든다.)
   숫자 필드는 사람이 읽기 좋은 문자열(예: `"+60.37"`, `"18조 2,000억원"`)로 넣는다.
   `branch_name`/`department`/`author`/`contact` 는 별도로 지정하지 않으면
   `render_report.py`가 인천프리미어센터·인턴·김형준·010-5912-9992로 기본값을 채운다.

5. **렌더링 실행.**
   ```
   python3 scripts/render_report.py data/{YYYY-MM-DD}.json
   ```
   `reports/{YYYY-MM-DD}_market_report.md` 와 `.html` 이 생성된다.

6. **간단 검증.** 생성된 `.md` 파일을 열어 표가 깨지지 않았는지, 이슈 종목 이유가
   빈 값("TODO")으로 남아있지 않은지 확인한다. 문제가 있으면 다시 채워서 5번을 재실행한다.

7. **결과 전달.** `SendUserFile` 로 `.html` 파일(및 원하면 `.md`)을 사용자에게 보낸다.
   메시지에는 오늘 코스피/코스닥 등락률 한 줄 요약을 포함한다.

8. **저장소에 커밋.** `reports/{YYYY-MM-DD}_market_report.md/.html` 과 `data/{YYYY-MM-DD}.json`
   을 커밋하고 지정된 브랜치에 푸시해 이력을 남긴다.

## 참고: 로컬 PC/사내 서버에서 완전 자동화하려면

이 원격 세션 환경은 조직 보안 정책상 KRX/네이버 금융 등 원본 데이터 사이트에 직접
접근이 막혀 있을 수 있다. 만약 사용자가 자신의 PC나 자체 서버에서 크론(cron)으로
돌린다면 `scripts/fetch_pykrx.py`가 실제 네트워크 제약 없이 코스피/코스닥 지수와
등락률 상위 종목을 자동으로 가져올 수 있다:

```
python3 scripts/fetch_pykrx.py --out data/$(date +%F).json
# 이후 issue_stocks 의 reason, checkpoints 등 정성적 항목만 사람이 채우거나
# Claude에게 위 2~3단계를 수행하도록 시킨 뒤
python3 scripts/render_report.py data/$(date +%F).json
```

크론 예시 (평일 16:00 KST 실행):
```
0 16 * * 1-5 cd /path/to/Daily && python3 scripts/fetch_pykrx.py --out data/$(date +\%F).json && python3 scripts/render_report.py data/$(date +\%F).json
```
